# Easel

Drawing and painting app with layers, brushes, and Apple Pencil support, for iPhone, iPad and Mac.

- `Easel`: the iPhone and iPad app.
- `EaselMac`: Easel for Mac, a native AppKit document app.
- `Shared`: the editor, panels and document handling both apps use.
- `Paintbrush`: the drawing engine (model, rendering, Photoshop and Pixelmator Pro files), a framework shared by the apps and their extensions.
