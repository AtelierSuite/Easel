# Easel

Drawing and painting app with layers, brushes, and Apple Pencil support, for iPhone, iPad, Mac and the web.

- `Easel`: the iPhone and iPad app.
- `EaselMac`: Easel for Mac, a native AppKit document app.
- `Shared`: the editor, panels and document handling both apps use.
- `Paintbrush`: the drawing engine (model, rendering, Photoshop and Pixelmator Pro files), a framework shared by the apps and their extensions.
- `Web`: Easel for the web, the offline web app at [easel.atelier.ktgk.app](https://easel.atelier.ktgk.app), with Paintbrush compiled to WebAssembly. See [Web/README.md](Web/README.md) and [Web/PLAN.md](Web/PLAN.md).
